# 训练过程 checkpoint 评测

更新日期：2026-10-21。README 与各模型卡只报告**已发布的正式权重**；本文档集中记录训练过程中各 checkpoint 的 CJ-Bench 全量结果，供复查训练动态与选模依据。

## 口径

- **评测对象**：训练中按验证集分布 NLL 选出的 LoRA adapter，**合并前、T = 1**（不做温度校准）。发布权重是同一训练的最终 checkpoint 合并进基础模型后、使用默认温度的结果，每个表的最后一行列出以便对照。
- **测试集**：CJ-Bench 全部 307,900 条（硬标签 304,822、软标签 3,078），保留原始候选顺序，无过滤、无截断。ACC / ECE 只计硬标签，ECE 为 15 个等宽分箱；专业平均为医疗、法律、金融等权平均。所有选模与温度拟合只使用验证数据，没有使用测试集标签。
- **训练进度**：按实际已训练样本数计算（每步样本数不固定）。三个尺寸的全局 batch 不同（0.8B 约 1,024，2B / 4B 约 2,048），步数不能直接对照，应按样本进度比较。
- **验证集 NLL**：CJ-Dataset 官方 validation 的分层子集（4 领域 × 3 题型 × 100 条，共 1,200 条），用于模型选择，不是测试集成绩。

单位均为 %（验证集 NLL 除外）；↑ 越高越好，↓ 越低越好。
