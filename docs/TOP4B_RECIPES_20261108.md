# 4B 榜单前排的训练套路，以及我们冲第一的路径（2026-11-08）

数据来源：
- 榜单：[Decision Index 0.4.1](https://multimodalart-jev-decision-index.static.hf.space/index.html) 的 `data/index.json` 和 `data/v03.json`（生成于 2026-11-06 09:05 UTC，11-08 重新下载，内容未变）。本地副本在 `tmp/board-20261108/`。
- 模型卡：各模型的 Hugging Face 模型卡，本地副本在 `tmp/cards4b/`。
- 我们的模型：`runs/decision-index/pointer-4b-avg46-reverse`（第 2 轮和第 4 轮权重平均），公开分 61.69。

## 1. 先看清排名规则：公开分不计入排名

榜单 0.4 的排名用 **Full 分**：

```
Full = 0.6 × 私有同技能分（S） + 0.4 × 私有新领域分（O）
```

公开题集只做提交校验，**权重为 0**。

在 55 个 4B 模型里：
- 公开分和 S 的相关系数是 0.975，所以刷公开分基本等于刷 S；
- 公开分和 O 的相关系数只有 **0.57**，公开分高的模型，新领域分不一定高。

用 4B 模型做线性回归（S ≈ 0.79×公开分 + 6.2，O ≈ 0.42×公开分 + 16）：

| 公开分 | 推算 S | 推算 O | 推算 Full |
|---:|---:|---:|---:|
| 61.69（我们现在） | 55.2 | 41.8 | **49.8** |
| 65 | 57.8 | 43.2 | 51.9 |
| 67 | 59.4 | 44.0 | 53.2 |

**结论：即使把公开分刷到 67，推算的 Full 也只有约 53，进不了前三。** 想拿第一，必须单独把 O 拉上去。

## 3. 前排共同的套路

### 3.1 按 Full 的代理分选模型，不按公开分选（KnowLine，影响最大）

KnowLine Gen5 卡里写得很直白：
- 去掉所有"按 Decision Index 基准格式写的训练行"，公开分掉了约 20 分，新领域分几乎不变；
- 他们的 35B 模型公开分第 7，Full 却排第 27。

所以他们自建了两类留出集：
- **姊妹集**：同一技能、换一份数据（对应 S）；
- **新领域集**：训练里没有的领域，18 个真实文本决策任务，比如退款、水电账单、申诉、资格审核、多语言请求、法律问题（对应 O）。

然后用 `0.6×姊妹集 + 0.4×新领域集` 挑存档。

Gen5 的数据也朝这个方向调整：
- 原样照搬基准格式的题减少，换措辞的版本增加；
- 新增真实、有歧义的判断题，涉及商业政策、多语言、法律合同、表格、人类判断、三段论；
- 规则执行、算术、逻辑谜题这类程序生成题减少。

### 3.2 推理时读两遍：不用训练，KnowLine Full +2.3

做法：对不超过 3,000 token 的纯文本请求，把整个输入（状态、题目、选项）再写一遍，前面加一句"Read the same input again before answering:"。

KnowLine Gen5 → Gen5.5 权重完全相同，Full 从 53.68 升到 55.99，正是这个改动让它从第 2 变成第 1。Cerno 和 Senova 也用了读两遍。

**我们能不能直接用，需要实测。**
- 我们的全注意力层已经对整个提示双向，这部分已经"边读状态边看到问题"了。
- 但 Qwen3.5 每 4 层里有 3 层是线性注意力（Gated DeltaNet），这些层仍然是因果的，读状态时还看不到问题。读两遍对这些层可能仍然有效。
- 延迟要求是每个请求不超过 1,000 ms，4B 模型读两遍后仍远低于这个上限。

### 3.3 蒸馏大模型的完整概率分布：O 最高的做法（Perplexity）

- Perplexity Flash 公开分只有 60.06，但 O 是 4B 里最高的（52.07），因此 Full 排到第 3。
- 它的做法是让 4B 学 27B 决策模型在训练请求上的**完整选项概率分布**，不只是学正确答案。卡上说蒸馏"也提高了训练中完全没出现过的决策任务"。
- 榜单上大模型的 O 远高于 4B：27B/31B 模型在 66～80，4B 在 44～52。从大模型蒸馏，是把 O 拉上去最直接的办法。

Cerno 的做法类似但成本更低：用 DeepSeek-V4.1-Flash 给多领域合成决策题打分布，当软标签用。

### 3.4 多个种子做权重平均

| 模型 | 做法 |
|---|---|
| StartLux | 4 个种子取均值 |
| Verdin | 3 个种子，比单种子均值高 0.6～0.8 |
| KnowLine | 两条训练线（从底座重训一个 + 老线续训一个）做 50/50 平均 |
| Perplexity | 多次训练取均值 |

我们目前只做了同一条训练线前后两个存档的平均（avg46，+0.08），这不是真正的多种子平均。

### 3.5 数据规模和形式

- **规模**：前排 310 万～520 万行，我们约 110 万题。
- **软标签**：Senova 用选项级软标签，Cerno 用教师分布。
- **去偏**：普遍会打乱选项顺序，并修正标签比例。
- **去重**：都按 13-gram 之类的规则和测试集去重。私有题如果发现训练重叠，那一项不计分。

### 真正的未知数是 O

我们从没在榜单拿到过真实的 S 和 O。最近 4 轮专门照着基准格式补数据（iSarcasm 官方训练集、POP909 和弦题、BBH 风格谜题），这些对 S 有帮助，但可能让 O 往 Amber Hybrid 的方向走。

## 5. 冲第一的路径

目标：Full > 56，比如 S ≈ 60.5、O ≈ 51，Full ≈ 56.7。按推算，我们现在大约是 S 55、O 42。KnowLine 每 1～2 周就会发新版，所以目标要留出余量。

### 阶段 0：本周，不训练

1. **提交当前最好的模型（avg46），拿到真实的 S 和 O。** 之后所有决策都依赖这个基线。提交是公开发布，需要你确认。
2. **读两遍 A/B 测试。** 在引擎里加 `read_twice_tokens` 选项，先在约 1.5 万题的分层抽样上对比，有效再跑全量。成本约半天，预期 0～+2 Full。
3. **建 Full 代理集，换掉公开分这个选模型标准。**
   - 姊妹集：每个公开基准找一份同技能的其他数据，比如 RAGTruth 用 HaluEval/FaithDial 的留出部分、ESCI 用 WANDS、VAST 用 P-Stance、iSarcasm 用 SARC 或 Headlines 留出、GSM8K 用 SVAMP/ASDiv、BANKING77 用 HWU64；
   - 新领域集：15～20 个训练里没有的真实文本决策任务，比如合同条款、保险理赔、报销政策、招聘筛选、医疗分诊、表格判断、中英混合客服，每个 200 题、标签均衡；
   - 选模型标准改成 `0.6×姊妹集 + 0.4×新领域集`；
   - 这些集合必须从训练数据里剔除。

### 阶段 1：1～2 周，从底座重训

4. **数据扩到 300 万题以上，并往新领域、真实文本倾斜。**
   - 按基准原格式造的题降到约 20%，其余换成改写措辞和改写题型的版本；
   - 新增商业政策、法律合同、表格、多语言、偏好判断类真实文本；
   - 训练时随机打乱选项顺序；
   - 对已有数据（decision-mix-v1～v6、tasksource 等）重新按来源配比。
5. **教师软标签。** 用 156 上的 Qwen3.6-27B，或可用的 DeepSeek 一类 API，给多领域合成题和无标注真实文本打选项分布，按 Cerno 的做法当软标签。不能用 Jev 的输出。
6. **对比 LoRA 和全参数微调，比较时只看代理集。** Verdin 发现 LoRA 更好，StartLux、Senova、Cerno 用的是全参数。我们在 A800 上可以两种都跑一次小规模的。
7. **3～4 个种子做真正的权重平均**，种子之间换数据顺序。预期 +0.5～0.8。

### 阶段 2：2～4 周，上限最高

8. **训练自己的大教师，再蒸馏到 4B。**
   - 用同一套数据和读出方式，在 A800 上训练 Qwen3.5-27B（或先用 9B 试）决策模型；
   - 再用教师在全部训练请求和大量无标注真实文本上的完整概率分布，蒸馏 4B；
   - 这是 Perplexity 拿到 4B 最高 O 的做法。榜单上同家族 27B 的 O 比 4B 高 20 分以上，蒸馏能拿回一部分。
   - 不建议直接蒸馏其他参赛者的模型（例如 KnowLine 31B，O 79.6）。许可和规则都没有明确允许，StartLux 4B 还是 CC BY-NC 许可；如果真要用，先确认许可并在模型卡里写明。
9. **阶段 1 的老线和阶段 2 的蒸馏线做 50/50 平均**，参考 KnowLine Gen5 的做法。

### 预估（不确定性大，需要阶段 0 的真实基线来校准）

| 措施 | 预估 Full 变化 |
|---|---|
| 读两遍 | 0～+2（我们已经有双向注意力，收益可能比 KnowLine 小） |
| 按代理集选模型，数据往新领域倾斜 | O +4～6，约 +2 Full |
| 补短板，公开分到约 66 | S +3，约 +1.8 Full |
| 多种子平均 | +0.5 |
| 大教师蒸馏 | O +3～5，约 +1.5～2 Full |
| **合计** | **约 +5～8，Full 约 55～58** |

第一名门槛现在是 55.99，并且还会上涨。只做阶段 0 和阶段 1，大约能到前三附近；要稳拿第一，基本需要阶段 2 的蒸馏。

## 6. 建议马上停止的做法

- **按公开分逐项补数据、每轮只看公开分涨跌。** 这样优化的是不计分的部分，还有 Amber Hybrid 那样损失 O 的风险。
- **用 BBH 原题或任何测试题训练。** BBH 有 canary；私有题一旦查出重叠，那一项直接不计分。
